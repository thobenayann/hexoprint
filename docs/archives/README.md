# Archives

Documents d'implémentation d'origine du site. Ils étaient dans `public/doc/`,
donc servis publiquement sur hexoprint.fr. Ils ont été déplacés ici le
4 novembre 2026 pour ne plus être accessibles depuis le site.

Ces documents n'ont pas été relus depuis et peuvent être périmés.
`email-system.md` l'est déjà : pour la configuration actuelle des e-mails, du
formulaire et des protections anti-abus, la référence est
[`docs/securite.md`](../securite.md).

Tout ce qui est placé dans `public/` est publié tel quel. La documentation
interne va dans `docs/`.
